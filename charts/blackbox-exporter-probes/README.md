## Probe の欠測

`applications[].targets` と jobName から `pke_probe_expected` を生成し、`ProbeMetricsAbsent` で結果の消失を検知する。
期待する URL を別のリストに追加する必要はない。`probe_success=0` は EndpointDown、系列の消失は ProbeMetricsAbsent で扱う。
5分間結果がなく、その状態がさらに5分続くと critical を通知する。短い収集遅延や失敗を返す Probe は欠測として通知しない。
通知時は Probe の定義、Alloy の discovery、blackbox exporter と送信経路を確認する。
`prometheusRule.probeMetricsAbsent` で `for` / `severity` / `annotations` を設定できる。
